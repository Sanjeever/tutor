# Live2D 模型资源

应用内置两套 Live2D 官方免费示例模型，均用于课堂教师形象，用户可以在“课堂设置”中切换：

| 性别 | 模型 | 路径 |
| --- | --- | --- |
| 女老师 | Izumi（长袖上衣版本） | `assets/avatar/teacher-female/izumi_illust.model3.json` |
| 男老师 | Chitose（西装领带） | `assets/avatar/teacher-male/chitose.model3.json` |

两套模型均来自 Live2D 官方示例数据集，项目只保留官方运行时文件，没有重新绘制、裁剪或改写模型资源。它们的服装覆盖完整，不使用原先的暴露职业装头像。
